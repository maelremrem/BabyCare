# Contributing to BabyCare

Thank you for helping improve BabyCare. Contributions are welcome, especially around accessibility, touch ergonomics, tests, data reliability and self-hosting.

## Workflow

1. Open an issue for a substantial change when possible.
2. Create a focused branch from `main`.
3. Keep the existing architecture and UI conventions in mind.
4. Add or update tests for behavioral changes.
5. Run `npm run check` before opening a pull request.
6. Describe the need, the solution and the verification performed.

Pull requests to the official BabyCare repository are preferred so improvements can be reviewed and integrated upstream. Forks and modified versions remain permitted under the terms of the GNU AGPL v3.0.
